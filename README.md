# Portfolio idragood

Site statique (HTML, CSS, JavaScript), sans serveur ni base de données.

## Mettre en ligne avec GitHub Pages
1. Crée un dépôt sur GitHub et envoie-y **tous** les fichiers de ce dossier (index.html, style.css, script.js, favicon.svg, dossier images).
2. Dans le dépôt : Settings, puis Pages, puis Source : "Deploy from a branch", branche `main`, dossier `/ (root)`.
3. Coche **Enforce HTTPS** quand l'option apparaît.
